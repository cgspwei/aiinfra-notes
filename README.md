# AI Infra Notes

Personal study notes for learning AI infrastructure — the systems, frameworks, and engineering practices behind large-scale model training and inference.

The notes are written primarily in Chinese and stored as self-contained HTML pages (open them directly in a browser).

## Contents

### `pytorch-notes/`
Notes on PyTorch internals and the engineering behind large ML systems.

- `pytorch-build-system.html` — a deep dive into the PyTorch build system as a case study of a large multi-language codebase.
- `pytorch-senior-aiinfra-roadmap.html` — a learning roadmap for PyTorch / deep learning aimed at a senior AI Infra engineer level.

### `vllm-notes/`
Notes on vLLM, a high-throughput LLM inference and serving engine.

- `vllm-overview.html` — project overview.
- `vllm-architecture.html` — architecture at a glance.
- `vllm-hard-parts.html` — where the hard problems are.
- `vllm-reading-path.html` — a suggested source-code reading path.
- `vllm-learning-roadmap.html` — a roadmap for studying the architecture and source code.

### `reading.md`
Links to external reading material.

## Status

A work in progress; notes are added and revised as I study.
